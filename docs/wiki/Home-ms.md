# Password Manager

Pengurus kata laluan Tkinter yang kecil daripada hari ke-30 kursus Udemy "100
Days of Code: The Complete Python Pro Bootcamp". Ia menjana kata laluan,
menyimpannya dalam fail JSON dan mencarinya mengikut laman web.

![Tetingkap utama](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/030-password-manager/raw/branch/main/docs/images/main-window.png)

## Fungsinya

- **Menjana** kata laluan rawak dan menyalinnya ke papan keratan.
- **Menambah** laman web, alamat e-mel dan kata laluan ke dalam `data.json`.
- **Mencari** laman web dan memaparkan alamat e-mel dan kata laluan yang
  disimpan.
- Terus berjalan apabila `data.json` tiada, kosong atau rosak.

> **Nota keselamatan.** Kata laluan disimpan sebagai JSON biasa dan tidak
> disulitkan. Ini projek pembelajaran; jangan gunakannya untuk kata laluan
> sebenar.
