# Password Manager

A small Tkinter password manager from day 30 of Udemy's "100 Days of Code: The
Complete Python Pro Bootcamp". It generates passwords, saves them in a JSON
file and searches them by website.

![The main window](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/030-password-manager/raw/branch/main/docs/images/main-window.png)

## What it does

- **Generate** a random password and copy it to the clipboard.
- **Add** a website, an e-mail address and a password to `data.json`.
- **Search** a website and see the saved e-mail address and password.
- Keeps running when `data.json` is missing, empty or damaged.

> **Security note.** The passwords are stored as plain JSON and are not
> encrypted. This is a learning project; do not use it for real passwords.
